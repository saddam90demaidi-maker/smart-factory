مدير المصنع الذكي — نسخة PWA تجريبية مبنية على V120

1) ارفع جميع الملفات الموجودة في هذا المجلد معاً إلى استضافة HTTPS (مثلاً GitHub Pages).
2) افتح رابط index.html على هاتف Android عبر Chrome.
3) من قائمة المتصفح اختر تثبيت التطبيق أو إضافة إلى الشاشة الرئيسية.
4) قبل إدخال أي بيانات فعلية، افتح تبويب البيانات واستورد نسخة JSON الاحتياطية الحديثة.
5) قارن عدد سجلات الإنتاج والإخراج وأرصدة المواد والمخزون والتقارير مع النسخة الأصلية.
6) اختبر فتح التطبيق بعد قطع الإنترنت.

تنبيه: التطبيق الجديد يستخدم تخزيناً محلياً مستقلاً عن ملف HTML القديم. لا تنتقل البيانات تلقائياً.
تم تعطيل النسخة الاحتياطية القديمة المضمنة داخل كود V120 حتى لا تظهر كأنها بياناتك الحالية.
النسخة تجريبية؛ لم يجر اختبار كامل للحسابات أو الحذف أو الاستعادة على هاتف المستخدم.
الاستضافة تحتوي ملفات البرنامج فقط، ولا ترفع النسخة الاحتياطية أو بيانات المصنع.
لا تحذف تطبيقك القديم أو النسخة الاحتياطية الأصلية قبل التحقق.
